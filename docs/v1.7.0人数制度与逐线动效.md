# v1.7.0 人数制度、16人替补与逐线动效

## 赛前设置

进入「赛前准备 → 比赛人数与名单规则」，单选5、7、8、9或11人制；人数包含1名门将，默认11人，旧存档沿用11人。

1. 选择人数后，原名单暂留为草稿，顶部会列出两队人数与校验问题。
2. 点击「按人数整理两队首发／替补」，弹窗核对两队首发；多余首发转入替补，人数不足则补空白行等待填写。不会直接删球员。若转入后替补超过16人，操作整体拒绝，请先移除不报名者。
3. 展开「首发、替补与逐线翻牌」，选择编辑球队，核对姓名、号码、门将及逐人分线。可将首发转替补、将替补转首发，或增加空白行；首发不能超过所选人数，替补最多16人。移除球员需确认。
4. 选择适用于该人数的阵型模板，点击应用；或在逐人行指定门将、后卫线、中场线、前锋线，再点「按分线生成自定义阵型」。具体担任位置仍可从选项选择或自行输入。球场预览可继续拖动位置。
5. 核对两队后点击「将已编辑阵容同步到比赛」，确认本场报名名单；点击「更新直播资料」发布队名、素材等资料。选择并预览包装后，再播出所选画面。

只有首发恰好为所选人数、恰好1门将，球员身份/本队号码不重复且姓名完整，才允许同步、发布资料及播出首发/阵型/替补。草稿自动保存不等于播出。切换编辑球队不更改比赛阶段。

已开始比赛或已有事件后，不能直接更改人数或换人方式；请先导出保留旧比赛，再用准备好的名单新建比赛。新建会清空本场账本，必须确认。名单同步不会改写既有换人后的原始首发；若删掉关联球员导致历史处罚或换人失效，会拒绝更新。

## 阵型与自定义分线

| 人数（含门将） | 预设 |
|---|---|
|5|1-2-1、2-1-1、2-0-2、1-1-2|
|7|2-3-1、3-2-1、2-2-2、3-1-2|
|8|3-3-1、2-3-2、3-2-2、2-4-1|
|9|3-3-2、3-2-3、2-4-2、4-3-1|
|11|4-3-3、4-4-2、4-2-3-1、4-1-4-1、4-4-1-1、4-3-2-1、3-5-2、3-4-3、5-3-2、5-4-1|

阵型数字不含门将；多层中场模板会把各中场行归入中场线，球场位置仍分别保留。自定义阵型由后卫／中场／前锋人数生成，允许某条线为0，三线总和必须等于人数减1。空线不会生成介绍页。超过5人的分线每批最多5人，全部介绍后才在阵型图中揭示整条线照片；球场图会按横向间距缩放，密集自定义摆位仍建议手动核对并拖动。

独立首发名单按人数适配；替补16人使用两列各8人，保持与首发右侧区域相同尺寸。

## 换人和比赛规则

「允许换下球员再次上场（滚动换人）」为可选项，默认关闭。关闭时换下球员进入已换下名单，不能再选为换上；开启时返回替补席，可再次检索上场。两种方式都保留最初首发。被罚下者不能上场或用换人补足；替补/官员红牌不减少场上人数。

人数选择只设置报名人数与阵型，不会自动修改半场时长、停止计时或更换点球大战规则。半场时长仍在计时台按赛事规定设置；系统不会自动执行五人制红牌后补人或净比赛时间等专项规则。

## 展开与收起

用户已确认采用：球员卡从左向右依次淡入、由小放大；每张间隔140ms，先停顿，快速展开、尾端减速并停稳。随后按原设置翻牌、展示照片/静音视频。媒体停留结束后，整组右侧画面在700ms内向左像窗帘一样收起，再回到已更新照片的阵型图。缺媒体仍使用球衣。两队依次展示时保留整页翻转。

左下信息仍从左侧竖线开始；居中包装仍从中心向两边展开，再展开上下附加区。两者均增加明确的开始停顿和结束停顿；收起按相反方向执行，提前撤下与切换也保留收拢。紧急清屏即时清掉副本和队列。动效只影响图形，不改变比分、计时或账本。

## 预览与故障

启动程序后打开 http://127.0.0.1:3210/lineup-motion-preview.html 。可选分线和主题、循环或点击「重播动画」「窗帘式收起」。该页只读取草稿，不写账或误播。

录制文件：design-previews/v1.7.0/line-motion-demo.webm，可用浏览器打开；截图和验证结果同目录。如果本地网页连接被拒绝，先运行启动程序并确认启动窗口显示后台地址，再刷新；页面依赖本地服务，单独双击HTML无效。

五种人数的可导入示例放在 examples/formats/ 。导入会替换比赛并暂停计时，请先导出自己比赛。
