# 整场演示与验收

日期 2026-10-19，所有演示球队、人物和统计均为虚构示例，不能用于真实比赛播报。

## 完整演示存档

后台「存档与素材」导入 `public/data/full-match-demo.hust.json`，或点击载入完整演示。它包含 3:3 本场、首回合 1:1/总比分 4:4、点球八轮 6:5、无效进球、两黄变红、多人换人、统计、原始首发和当前名单。内置剪影演示逐线翻牌；不是实际球员照片。结果对象填好但未确认，须自己确认后才显示冠军。

生成方式：`node scripts/make-demo.mjs`。该脚本只生成文件，不改当前比赛。

## 从零逐步操作

1. 导出备份→新建空白比赛。双方名单编辑后同步；选择 PULSE。关闭不需要的模块，预览两套主题关键画面。
2. 播出流程→开场顺播。观察 intro→opening→entrance→主队名单/阵型→客队名单/阵型→裁判→开球→底部比分→左上常驻。提前结束可跳过任意画面。
3. 选上半场→切换→开始。校准 44:58、宣布 +2；观察过 45:00 后继续。暂停并设置独立补时，再继续；事件时间可手输 45+2′。到达宣布时长后不会自动结束。
4. 分别记录主队 23′ 9号陈子昂、客队 39′ 8号周奕辰进球。事件动画重播三次，检查比分仍 1:1。切中场得到半场 1:1；半场顺播与底部半场比分只含这两球。
5. 切下半场，起点45:00→开始；底部下半场开场比分 5.5 秒后回常驻。主队67′点球进球→2:1；底部重开球显示该球。
6. 主队75′再进一球→3:1；进球无效关联该球→2:1，结果卡、有效进球列表和待播进球同时修正。修正球员姓名、号码、时间或类型，再看赛果。
7. 选主队吴承泽，连记两次本场黄牌，常驻红牌1。给替补/教练红牌，场上红牌数不增加。撤销第二黄，场上红牌回0；恢复后回1。
8. 客队选择两组换下/换上→同批记录；当前名单改变，原始首发不变。动画按组展示，重播不再次换人。试重复换人应被拒绝。
9. 客队90+2′进球→2:2。切常规结束→加时上半场从90:00→主队98′进球→加时中场→加时下半场从105:00→客队117′乌龙受益球→3:3。切点球大战。
10. 点球清空、主队先罚。先测主进客失各三次，3:0提前决胜但不自动确认；确认后再修改一脚，应取消确认。设待重罚→胜负提示撤销→重罚。
11. 再清空，逐轮主/客输入：1/1、1/0、0/1、1/1、0/0、1/1、1/1、1/0。第八轮主6客5，需人工确认。期间用底部简版，结束用大面板；本场进球仍3:3。
12. 首回合填1:1，启用总比分→4:4，客场进球默认关闭。最终对象选主队、冠军、勾确认→保存；切全场结束→全场流程。进球者含P/OG，点球比分单独显示。
13. 录统计（可照演示存档），把某项留空，输出不显示该项；填合法0则显示0。人物、解说、鸣谢分别单独预览/播出。
14. 当前播进球，连续加入统计、换人、给牌，查看队列优先级；统计不能打断进球。点紧急清屏，等待10秒无旧弹窗，再恢复常驻。
15. 延迟设3秒，记球并播出；观察实际输出比分、计时、事件按同一延迟变化。清屏立即生效。结束后延迟改0。
16. OBS刷新/源隐藏再显示，检查时钟不从头，事件不重复。停服重启，检查队列清空、时钟暂停并出现恢复选择，确认后继续。导出/导入，检查上传素材仍在。

## 自动验收与边界

`node --test tests/*.test.mjs`：时间戳、阶段与校园时长、补时、事件幂等、取消/依赖、红牌对象、多人换人、未知统计、两回合、点球重罚、队列、统一延迟、清屏、项目移机、服务恢复、素材校验、真实中文路径 CMD 启动。

`scripts/review-v1.cjs`：Edge 实际页面、两主题各26画面截图、UI开始计时/事件预览/记账/重播、透明与清屏。记录在 design-previews/v1/validation.json。早期 v0.2 的逐线照片/视频、长名/缺图检查材料保留在历史预览目录。

自动化不是 OBS 实机推流测试。目标设备还须检查：1080p60帧率、OBS资源占用、长中文名称与不同队徽比例、10轮以上点球、并发浏览器源、上传视频解码和提示音、长时运行。没有实测前不报告虚构FPS或性能百分比。
