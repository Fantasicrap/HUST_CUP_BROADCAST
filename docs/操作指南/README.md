## 第一次使用的顺序

1. 安装Node.js 20+，解压完整程序，双击启动系统.cmd，保持READY窗口打开。
2. OBS添加1920×1080浏览器源，填写 `http://127.0.0.1:3210/overlay.html?mode=live&transparent=1` 并放在视频上方。
3. 到赛前准备按“资料 → 阵容 → 画面 → 开播”操作。已有比赛先导出；仅新比赛需要确认新建。
4. 资料步骤选择人数和换人制度、填写双方与赛事。阵容步骤核对首发N人含1门将、替补≤16，再同步名单与规则。
5. 画面步骤按需＋添加裁判、填解说备注、赞助和通用人物；照片视频可选。设置主题与模块，预览后发布资料。
6. 开播步骤处理检查提示，明确发布后播开场、入场和双方阵容；实际开球才应用比赛阶段开表。

## 赛中主要操作

事件名称 → 填写并检索球员 → 确认并预览 → 应用并播出。号码和姓名绑定；已应用但未看见动画时先查日志、队列与延迟，不重复录入。

计时“应用”在同阶段继续，在更改阶段时使用起点；暂停不改变阶段。校准可输入 `-00:10` 或 `+00:10`。清零需确认，只清时间并暂停。宣布+n分钟不会限制实际补时，到点不会自动结束。

普通进球无额外标记，点球(P)、乌龙(OG)。乌龙选球员所属队、对方加分，记录在乌龙方。取消进球须选原有效记录和原因。VAR只显示判罚决定，改变比分或处罚仍需关联撤销。

多人换人逐组添加后一起确认、整批记账、逐组播放。普通同批多人扣多人名额、1个窗口。新项目默认5名额/3窗口；脑震荡默认关闭。启用后明确选“脑震荡换人”，对方实际获赠后才有额外选项及（+1）显示。规则与示例见上方换人文档。

## 中场 加时与赛后

裁判实际吹停后，明确应用中场或结束阶段；导航本身不停表。中场期间换人扣名额不扣窗口，普通暂停不免窗口。下半场真正开球后才应用下半场；半场及下半场开球底部条使用同份有效上半场记录。

点球大战另开专用面板，逐脚记进/失或重罚。提前决胜、突然死亡由系统提示，结束仍须人工确认。点球不计入比赛进球者。全场实际停表、核对账本、人工确认赛果后再播出并导出项目。

## 预览与播出别混淆

| 按钮 | 作用 |
|---|---|
| 同步名单到比赛 | 更新检索、规则和记账依据 |
| 发布资料（不换画面） | 发布队名、队徽和主题等草稿，不启动动画 |
| 预览此画面 | 只看包装，不播出、不记账 |
| 正式播出此画面 | 正式送播所选包装，忙时排队 |
| 事件的应用并播出 | 记录比赛事件并送播，重播请用日志 |
| 结束包装，回到比分牌 | 结束包装和清队列，比赛阶段才显示左上 |
| 紧急清屏 | 两路包装和队列立即撤下，不停表、不删账本 |

二路进球入口位于赛中折叠区，它只有动画，不加分。主路进球必须另行录入。后台作者署名可在本浏览器关闭，输出无可见水印。
