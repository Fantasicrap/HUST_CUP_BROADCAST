# v2.0.0 换人制度与整场操作更新

本版为可本地运行的完整足球OBS图文系统，保留PULSE、NOCTURNE两套主题。建议下载Assets中的 **HUST_CUP_BROADCAST-v2.0.0.zip**，完整解压后启动；单独的新版Word指南也在Assets中。

## 主要更新

- 赛前按“资料 → 阵容 → 画面 → 开播”准备；赛中集中显示计时、事件、预览与实播状态。
- 裁判全部岗位按＋添加，附加助理不显示括号序号；裁判和解说可填备注；通用人物条单独配置。
- 默认每队5个普通换人名额、3个窗口，赛前可修改或关闭限制；多人同批记账后逐组展示。
- 中场、加时前休息与加时中场扣名额免窗口；普通暂停仍算窗口，沿用仅限同一次实际暂停。
- 可选永久脑震荡换人，每队最多1次，不扣普通额度，对方获得专项1名额/1窗口。明确选类型才执行，未实际赠送不显示（+1）。左下换人条下展显示剩余额度。
- 修复保存/预览竞态、半场补记归属、两黄累计、延迟误发布、二路连续播出时间线、模块开关和多人播放时长。
- 项目介绍、18章22页Word指南及首页六场景图更新到v2.0.0，包含当前按钮、二路斜体、署名开关与整场演练。

## 下载与使用

1. 安装Node.js 20或更新版本。核心播出不需要npm install。
2. 解压完整ZIP，双击“启动系统.cmd”，看到READY后保持窗口打开。
3. 后台地址为 http://127.0.0.1:3210/ 。OBS浏览器源为 `http://127.0.0.1:3210/overlay.html?mode=live&transparent=1`，尺寸1920×1080。
4. 先在演示比赛练习，再准备真实名单。使用前请阅读包内docs/操作指南中的v2.0.0指南。

可选本地抠图需要另外安装Python环境及模型；不使用抠图也能完整运行核心系统。回放转场为图形包装，视频回放与推流由OBS负责。

## 从旧版升级

先导出项目并备份runtime，再择时停止旧服务、更新程序、重启并刷新后台及OBS源。重启后核对暂停计时和离线时间处理。旧存档保留原无限制换人制度，不会追溯套用5名额/3窗口；新项目采用默认值。请保留自己的runtime，不要用演示数据覆盖本场比赛。
