# 二路独立进球动画（v1.8.2）

## OBS接入与操作

后台在「赛中 → 二路·独立进球动画」。OBS新建浏览器源，地址 http://127.0.0.1:3210/goal2.html ，宽1920、高1080；建议60fps。空闲及结束自动透明，动画期间为不透明深色背景。需要单独推送二路时在另一OBS场景/实例使用该地址，视频推流本身由OBS负责。

点「选择球员／预览」→选进球队→输入号码或姓名并从候选选择→每段3/4/5秒→确认预览→应用到二路。默认4秒。每段三档字号闪动，GOAL后450ms快速翻转，再显示姓名和号码；最后550ms收起。总时长为两段+1秒。左下插画球衣按所选球队已发布的本场球衣颜色着色，背景为同色压深渐变与首发同款几何纹理，足球独立沿弧线越过GOAL，从朝左的球门开口进入右侧球网，落到网底后停止旋转和位移；翻转为姓名号码后，足球仍保持在网内，直到整个动画收起。

「修正二路姓名／号码」打开独立窗口；只修正本次二路文字，不改名单、进球记录或比分。修改选择、时长或文字后需重新确认。球员来自本场已确认报名名单（包括替补及已换下者），避免与未发布草稿混用。球队球衣色如需修改，应先在主后台预览并更新直播资料。

重播不重复加分、不生成比赛事件，也不切主路包装。二路可单独撤下；主后台的紧急清屏会一并清除二路。新建/导入比赛、服务重启均清空二路，不重播旧片。刷新二路源时根据时间戳从正确位置继续，结束后保持透明。二路继承已经发布的统一输出延迟；预览不延迟。声音关闭。

## 本机REST接口

所有写接口只接受本机同源，JSON请求；接口不写比赛账本。以实际端口为准，默认3210。

|方法/地址|用途|
|---|---|
|GET /api/goal2/roster|返回revision及teams.home/away，各含本场球员id、number、name与球队球衣色|
|POST /api/goal2/preview|准备预览，返回token、payload和durationMs，不播出|
|POST /api/goal2/play|用token正式播二路，重复提交同token不重播|
|POST /api/goal2/control|action为clear或replay|
|GET /api/goal2/state|run、serverNow（含统一延迟）、last（是否可重播）|

preview示例（playerId须从roster取真实值）：
```json
{"team":"home","playerId":"home-p-2","seconds":4}
```
文字修正追加：
```json
{"override":true,"name":"修正姓名","number":9}
```
play示例：
```json
{"token":"preview接口返回的token"}
```
预览token有效15分钟，比赛账本版本变动会使其失效，需要重新确认；不支持跳过检索直接传任意姓名正式播出。单次时长只能为3/4/5秒。清屏即时生效。浏览器源在断连两秒后隐藏；重连只接受当前有效播放，不回放已过期片段。

## 本地素材与实现

public/assets/goal2-kicker.png为基于用户上传插画、使用内置imagegen编辑得到的透明PNG。背景和足球已拆离，衣服中的纯绿为运行时着色遮罩，不会按绿衣直接播出；动态着色保留皮肤、头发、裤子、鞋袜与黑线。独立足球及门框为本地SVG，字体沿用本地优设标题黑；所有必要素材离线可读。

使用的最终提示词（内置工具，未使用CLI或单独API密钥）：
> Edit target: the attached cartoon soccer player illustration. Produce a clean transparent PNG animation asset. Preserve the exact player pose, black spiky hair, peach skin, blue shorts, black boots, white socks and hand drawn style. Remove the entire white background, remove the football and all airborne motion trails on the upper right; retain only the complete footballer, without any ground marks. Make the shirt ONLY a flat saturated pure chroma green #00FF00 (no gradients, no other green anywhere), preserving the black collar, sleeve edges and black fold outlines. This green is a technical mask to be recolored at runtime to each team's kit color. No text, no new objects. Keep the whole player visible with a small transparent margin, landscape composition, about 1300x750. Actual transparent alpha, not a checkerboard.

这是图形二路输出，不包含二路视频信号采集和推流。实际流畅度/OBS资源占用仍按目标设备测试。


## v1.8.1 球门方向与停球修正

球门分为后方球网与前方门柱，门口朝向左侧射门球员。飞行路径增加门外下落与穿过门口的阶段，足球从门口进入，在网底停稳，姓名号码阶段不再淡出或继续旋转。3/4/5秒单段时长采用相同位置，仍按原时长自动结束。

仅修改图形文件，正在运行的服务不需要重启。后台与OBS浏览器源刷新后读取新版。此补丁不修改接口、记账或主路状态。录像为design-previews/v1.8.1/goal2-net-demo.webm；逐帧检查及两路隔离验证结果在同目录。


## v1.8.2 原字体正体姓名与标准比例球门

姓名继续使用用户提供的优设标题黑原文件，关闭额外斜体，并在显示层用8°反向倾斜校正原字形，呈现正体；字体文件SHA256仍为dab883d69fb713233ea5d9aff8d1f27ccc2b71e249143edf6ea08367784c5dba。姓名宽度仍按原字体测量，预留校正后边缘空间，较长姓名自动适配。三档大小动画保留。

本二路球门示意按十一人制标准净开口7.32米×2.44米，即3:1重新绘制；依据[IFAB规则第一章](https://www.theifab.com/laws/latest/the-field-of-play/)。门柱内侧与横梁下沿的图形净开口为558×186px，比例恰好3:1。整个含纵深球网的SVG为680×280px，使用相同比例的viewBox，无非等比拉伸。门柱和球网分层，足球轨迹及网底落点同步调整，仍在姓名阶段保持停球。

刷新后台及二路OBS浏览器源即可，不需重启计时服务。完整录像design-previews/v1.8.2/goal2-net-demo.webm；新字体与几何逐帧检查、原二路回归证据均在同目录。
