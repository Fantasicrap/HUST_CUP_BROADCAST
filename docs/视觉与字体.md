# 视觉与字体规范

五色主题：#85C9FC、#86EFFC、#4E60FC、#1355FC、#FFFFFF。深蓝底和文字深色为辅助明暗色。黄/红牌保留足球语义色，不能混淆处罚。

PULSE 使用白色信息面、竞技蓝赛事中心、冰蓝强调线、几何结构和约 350ms 滑入；NOCTURNE 使用深蓝底、蓝紫渐变、光弧、冰蓝重点字和约 650ms 展示。两者共用数据、DOM 和播出调度。

默认 Noto Sans CJK SC Black，完整 OTF 本地提供，许可证在 public/fonts/OFL.txt，来源为 Noto 官方仓库。图片原字体未识别，经用户选择使用接近的开源粗黑方案，强调方正字面、粗字重和紧凑行距。后台支持 TTF/OTF/WOFF/WOFF2 上传，字体随项目导出；缺失时回退默认字体和系统雅黑。

画布 1920×1080，默认安全边距 96×64。单行常驻约 782×62，比分 35px、队名/时间 26px。扩展区附着下方，不推动主体。长队名优先简称；队徽、赛事 logo contain 等比缩放，缺失显示文字或原创奖杯。

左下事件约 530×92/120，底边距 90；底部比分居中 980×82，进球信息向上扩充；底部点球 820×131。阵容右区 1364×754，替补复用该区域，队长右上、累计黄牌左上。

全屏、底部比分和点球面板隐藏常驻；普通事件与常驻上下分置。全屏互斥，分层输出也遵守该规则。


## v1.1 比分牌修订（2026-10-19）

比分牌主计时器固定显示实际累计比赛时间，例如92:16；右侧补时块仅显示+n分钟，不再在下方显示宣布值/实际补时。后台的兼容补时格式只影响后台读数。进球、黄牌、红牌播出时，仅在对应球队下方展开事件与球员信息，退场收起。其他事件不占此扩展；总比分和点球辅助数值移至顶部小标签。

队徽上自动叠加场上红牌，最多4张；替补/教练不增加。球队资料中可手动+1/-1（0–4）或恢复自动，属于纯图形校正，不改处罚记录；须点击应用资料到实播或正式播出才能生效。事件扩展和红牌标记各自有开关。

本版25项自动测试通过，新增6组Edge浏览器检查通过。两套主题示例在design-previews/v1.1，证据validation.json。旧版验收记录保留；OBS实机性能边界不变。


## v1.1.1 修正（2026-10-19）

红牌标记移至对应球队计分板上沿，不依附logo；完整牌高26px，裁切容器高13px，仅露半张，最多4张。后台手动校正和自动处罚逻辑均保留。

事件分钟按“当前所在分钟”取整：常规区间 floor(实际秒/60)+1；达到本阶段规定结束点后为 阶段结束分钟 + floor(超出秒/60)+1。基点由比赛阶段和自定义半场/加时时长决定，与宣布补时无关。

| 阶段/时长 | 实际时间 | 自动事件分钟 |
|---|---|---|
| 上半场，45分钟 | 00:45 | 1′ |
| 上半场，45分钟 | 45:21 | 45+1′ |
| 下半场，45分钟 | 45:21 | 46′ |
| 下半场，45分钟 | 91:21 | 90+2′ |
| 上半场，40分钟 | 41:00 | 40+2′ |
| 下半场，45分钟，宣布+2 | 93:21 | 90+4′ |

宣布补时到时不会暂停、切阶段或自动播全场比分。计时运行时拒绝正式播出全场底部条和全场赛果；恢复计时会撤下/移除当前和待播的全场画面。预览仍与直播分离。应由操作员依裁判实际吹停先暂停或切到全场结束，再手动播出赛果。

已有日志中手动保存的时间不自动重写，纠错可在日志操作。26项自动测试通过，含分钟边界、自定义时长、超补时、运行中全场播出拦截和队列清理；6组本次浏览器验证通过，材料在 design-previews/v1.1.1。
