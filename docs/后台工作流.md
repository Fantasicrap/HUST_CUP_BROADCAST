# 后台工作流（v1.3）

后台默认进入“赛中”。左侧按比赛时间顺序分类，切换分类只查看相应工具，**不自动切换比赛阶段、不停表、不播出**。实际阶段仍在计时区选择并点击“应用”。

| 分类 | 主要操作 |
| --- | --- |
| 赛前准备 | 新建比赛；球队、队徽、赛事logo；首发/替补/球衣/照片/视频；同步阵容；两回合规则；裁判、解说与鸣谢；开场顺播；导入项目 |
| 赛中（默认） | 实播监看、计时/补时、实际比分±1；进球、给牌、换人等；事件日志与撤销；展开查看待播队列、手动图文和统计 |
| 中场休息 | 半场流程、半场底部比分；统计；下半场开球底部比分 |
| 加时与点球 | 手动选择加时阶段；先罚队、罚进/失、逐轮纠错和重罚、确认结束；底部简版和结果大面板 |
| 赛后 | 人工确认胜者/晋级/冠军和最佳球员；全场流程/底部比分；统计；导出含素材存档 |
| 系统设置 | PULSE/NOCTURNE、各模块独立开关、停留时间、位置/缩放；赛制时长、统一延迟、快捷键、VAR/回放/音量、字体 |

## 赛中常用操作

1. 选择阶段后点击“应用”：选项没变就继续计时，不归零；改了比赛阶段才按对应起点切换并开表；中场、结束和点球阶段保持暂停。宣布补时只填 +n，超过宣布时长仍走时。
2. 选择事件和球队，输入球衣号码或姓名搜索，再点选结果；姓名和号码自动绑定。支持方向键与Enter。换下/换上也可搜索，当前名单随换人更新；给替补/教练牌时选择对应对象。时间留空会自动取比赛分钟。姓名、号码和所属半场的修正项默认收起，需要时展开。
3. “待播预览”不记账、不播出；“仅记账”更新比赛数据；“记账 + 加入播出”同时排队播动画。日志中的“重播动画”不会重复记账。
4. “比赛实际比分”旁 ±1 直接记一条比分校正，实际输出按统一延迟同步。它不增加进球者，可从日志撤销。正式进球请用进球事件录入。
5. 展开“待播队列与其他图文”，可移除待播、跳过当前、手动选模块、选择进球后重新开球等底部场景。普通统计不会打断正在播的进球。
6. “紧急清屏”取消当前、队列与延迟缓存，时钟保持原运行状态；“只显示左上比分牌”结束其他包装并清空待播，只留下常驻，不改比分、计时或已发布资料。

## 监看与草稿

小监看默认显示真实 OBS 时间线，包括统一输出延迟。需要细看阵容或图文时点击“放大监看”。其下“预览模块与检查工具”收纳所有独立模块、透明底、安全框和长名称检查。

顶栏“选择画面”或监看下选择模块会进入草稿预览。“查看实际播出 / 返回待播预览”可切换监看方式，正式播出后自动监看实播。三个按钮的区别：

| 按钮 | 对直播的作用 |
| --- | --- |
| 更新直播资料 | 把队名、队徽、配色等草稿应用到当前画面，画面类型不变，动画不重播 |
| 播出所选画面 | 播放选择的开场、阵容、统计等画面；当前有临时包装则排队；选择本身不会播出 |
| 只显示左上比分牌 | 结束当前包装，取消待播队列，使用原有已发布资料显示常驻；不把新草稿自动应用 |

实播处于常驻，通常表示没有正在播放的其他画面；临时包装停留结束也默认回常驻。左侧分类只组织工具，不切直播。正式进球、给牌和换人使用事件区“记账 + 加入播出”，重复动画从日志重播。

“计时清零”只弹一次确认，确认后00:00并暂停，保留比分、事件和阶段；取消完全不变。“校准”无符号如45:00表示设置绝对时间，-00:10表示减十秒，+00:10表示加十秒，也可点±10秒。增减以服务端此刻的实际比赛时间计算，保持原运行状态，最低为零。

系统设置里另有“草稿比分检查”，该处 ±1 不直接改比赛，需明确应用。与赛中实际比分校正分开使用。

## 半场与赛后

中场先由操作员暂停计时、切换比赛阶段，再播半场流程。下半场开场可直接点“播出下半场开球比分”，按配置5–6秒后恢复左上常驻；之后仍需选择下半场并点击“应用”开表。

赛后先停表、核对比分和进球记录，再选择结果对象、称谓、勾选确认并保存。系统不会因为领先或时间到点而自动宣布结束、胜者或冠军。

统计表在赛中（默认折叠）、中场和赛后共用同一组输入，切换不会丢失未保存内容；点击保存才记入比赛。未知项目留空。导入/导出入口在赛前、赛后和系统设置，导入或新建前先备份。

## 球员号码与姓名检索

先在赛前准备完成名单，点击「将已编辑阵容同步到比赛」。赛中按所选主客队检索，不混用另一队；进球使用场上名单，替补给牌使用替补名单，换下/换上分别取当前场上和替补。已罚下者不再进入进球候选。原始首发仍保留，当前名单会随换人更新。

检索支持号码、完整姓名、部分姓名和位置文字，选中即自动填写号码/姓名，不需重复输入。输入新的检索词后必须重新选择，不会沿用旧球员；无结果会阻止相应进球/给牌或换人配对。仍可在「修正姓名、号码与所属半场」中对已选择球员修正文案，例如乌龙球特殊情况。
