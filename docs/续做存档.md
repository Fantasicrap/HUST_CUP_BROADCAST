## 文件与启动

运行 `node server.mjs` 或双击启动脚本，默认后台 3210，OBS 地址 `overlay.html?mode=live&transparent=1`。开发检查可使用其他端口；最终给用户使用的端口必须写清。

`runtime/state.json` 保存草稿/实播，`runtime/assets/` 保存上传文件，目录已被 Git 忽略。不要把用户个人上传混入源码压缩包；迁移电脑需一起复制 runtime。源码保持无外部运行依赖。

## 验证

`node --test tests/*.test.mjs` 包括模型和服务集成测试。浏览器开发脚本在工作区 work/review-v02.cjs，使用本机 Playwright、Sharp 和 Edge，以独立临时服务/存档检查，不改用户存档。新图在 design-previews/v0.2/。

已发现并修复 SSE 连接清理时机问题：应监听 res.close，不应在请求体完成时移除仍在工作的输出连接。对阵容刷新要用时间锚点，不能让重连从第一步重新开始。每次变更后运行相关验证；不要盲目重复所有检查。

## 额度规则

5 小时（300 分钟）额度剩余 ≤5% 时立即停止开发，保存文件、当前工作/验证情况与下一步，明天再继续。每个主要阶段前后检查；不要用周额度替代。不要自行使用额度重置。
