# v1.6.1 使用说明


## v1.6.1 比分牌可选对换与左下动效

系统设置 → 比分牌位置与显示 → 左上比分牌布局，提供「赛事logo居中、时间在右」（旧档默认）和「时间居中、赛事logo在右」两种。config.scoreboardLayout统一保存，草稿预览与正式发布分离；点击“更新直播资料”才进入OBS，导出与刷新保留。仅改左上常驻比分牌；底部简版和其他logo位置不变。补时始终在实际计时器右侧，包括居中时间布局；整体宽度、球队文字宽度、上沿半张红牌及两队事件锚点保持，圆角/实色/亚克力/两主题均可用。自定义上传赛事logo同样适用。

左下11类包装（进球、换人、给牌、点球、VAR、通知、人物、单项统计、赞助、解说、开球信息）统一先出现左侧4px竖线：约154ms显现，保持至440ms，再向右展开至1100ms。退场900ms：向左收回竖线、停顿、竖线淡出。底部居中包装和大面板保留中心展开及上下附加区，退场按相反顺序收拢。球队事件扩展向下出现、向上收回；阵容位置条从左向右出现、回到左侧收起，提前撤下亦有退场。紧急清屏立即移除现有包装、副本和队列。

所有动效只改呈现，不延迟账本或更改计时。检查覆盖自动到时、提前撤下、连续替换、取消扩展和清屏。49项Node、10项布局/发布/刷新、28项左下逐帧/大面板/位置条/事件扩展、22项分段动画及7组出入场/清屏/比分/日志回归通过。证据design-previews/v1.6.1。本机升级前计时暂停、无待播，先备份再加载新增配置，升级后全部match字段核验一致，并恢复原常驻比分牌选择。升级文件与私人runtime分离。
