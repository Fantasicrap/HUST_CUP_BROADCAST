# 中文使用说明

## 后台按比赛流程使用

默认进入「赛中」。左侧依次为「赛前准备」「赛中」「中场休息」「加时与点球」「赛后」「系统设置」。切换分类只是查看工具，实际阶段仍需在计时区选择并点击「应用」。刷新后也回到赛中，不改变已保存的比赛。

赛前填队名、名单、素材并同步阵容；赛中操作事件、计时与实际比分；中场填统计和播半场包装；加时与点球记逐轮结果；赛后确认赛果和导出；系统设置放主题、模块开关、自定义时长、延迟和快捷键。完整位置表见「后台工作流.md」。

小监看默认显示真实 OBS 输出，点击「放大监看」查看细节。展开其下「预览模块与检查工具」可选择独立模块，选择后进入草稿预览；「返回待播预览／查看实际播出」切换两种画面。顶栏直接选择画面，再点「播出所选画面」。选择本身只预览；「更新直播资料」只换资料、保持原画面；「只显示左上比分牌」结束其他包装并取消待播，保留已发布资料。

## 赛前资料

完整解压、安装 Node.js 20+、双击启动文件，保持窗口打开。首次含虚构演示数据，点击新建空白比赛后用于正式比赛。

编辑球队、简称、英文、队徽、赛事 logo、轮次、日期和场地；球衣色与品牌色独立。首发球员可编辑号码、姓名、分线、位置、球衣颜色、累计黄牌、队长、照片/静音视频；替补位置可选或自由输入。阵型可套常见模板和拖动位置。编辑完点击「将已编辑阵容同步到比赛」，或以当前草稿新建比赛。已有换人时，若修改导致依赖失效会拒绝同步，请先纠正关联事件。

所有编辑只影响草稿。选模块/主题仅预览，正式播出才进入直播；应用资料保留当前动画进度。赛中「比赛实际比分」的 ±1 立即生成比分校正记录并同步实际输出（设置延迟时统一延后），不生成进球者、不播放动画，可从比赛日志撤销。系统设置另保留「草稿比分检查」，该处 ±1 只改草稿，应用后才写入校正。动画重播绝不加分。字体在系统设置上传，缺失回退内置粗黑。

## 计时

选阶段→应用。与当前阶段一致时继续、不归零；选项改变时才切换阶段，比赛阶段从对应起点开表，休息/结束/点球阶段暂停。标准起点 00:00/45:00/90:00/105:00，自定义时长后按该长度计算，到时不自动结束。校准无符号 mm:ss 设置绝对时间，-00:10 减十秒，+00:10 加十秒，运行状态不变、最低为零。计时清零需弹窗确认一次，确认后00:00并暂停，比分、事件、阶段不变。

宣布 +4 与实际已进行补时分别显示，超过宣布值仍计时。累计显示例如 47:16，独立显示例如 45:00 +02:16；事件时间例如 45+3′ 独立保存。加时赛是单独比赛阶段。中断会保留先前阶段，切回该阶段保留中断时刻，再手动继续。隐藏图文、进球、换人等不会自动停表。

## 事件

选择球队、类型、对象；在球员栏输入号码或姓名检索，点选结果后姓名与号码自动绑定，不必重复填写。支持方向键和Enter，换下/换上同样可搜。候选来自赛前确认并同步的名单，随换人更新当前场上/替补；无匹配时不会沿用旧球员误记账。必要时展开修正项，时间留空自动取比赛分钟。「特殊进球类型」默认无（普通进球），普通进球不显示特殊标记；点球标P，乌龙标OG。乌龙的球队选乌龙球员所属队，点选该球员，系统给对方加分，播报和进球记录归乌龙方；无需把球队改成受益方。每次完成进球记账后特殊类型恢复默认普通。

待播预览用克隆数据，不记账、不播出。仅记账会更新比赛数据，记账加播出再进入队列。日志可重播动画、撤销/恢复、修正姓名与时间。牌色、进球类型和换人对象错误可撤销后重记；进球纠错还可修改号码与进球类型。有关联的记录先撤销后续依赖，再撤销前一条，系统拒绝破坏关联的修改。

第二张本场黄牌自动转红；赛前累计黄牌只用于阵容显示。替补/教练红牌不减场上人数。多人换人逐组添加，当前名单更新、原首发保留；罚下者不能换人。「进球无效」关联有效进球，同步比分、总结和待播队列。常规点球判罚/罚失填点球事件；罚进记为点球进球，与点球大战独立。

VAR 默认关闭，启用并应用后可播检查中、事项和最终结果。审核动画本身不取消进球，操作员还须执行关联取消。

## 播出

小监看下「预览模块与检查工具」中的顺播只用于预览；赛前／中场／赛后各自的正式顺播使用服务端队列。赛中展开「待播队列与其他图文」可管理队列和手动播出。优先级为进球/取消/给牌/VAR 90、换人/点球 70、其他大画面 50、统计/人物/鸣谢 20。等待队列按优先级排列，同级先入先出；正在播出的事件不被普通统计打断。明确「替换当前」可中断，「提前结束」切下一条。

开场流程为赛事开场→对阵→入场→主队首发/阵型→客队首发/阵型→裁判→开球→底部比分，只采用启用模块。任意一队任意模块可单独播放、跳过、结束或重播。逐线动画按门将、后卫、中场、前锋翻牌并保留照片，最后翻替补。

底部比分有开场、半场、下半场、全场、进球重开球五项，停留 5–6 秒再恢复常驻。重开球取最近有效进球，半场取上半场，全场取全部，较多进球分页。大画面/底部面板不与左上常驻重叠。

紧急清屏立即清空图形、队列与延迟缓存，时钟继续；恢复常驻重新挂比分。默认 Esc/F2/F3/F4，输入框内停用，设置页可自定义。

## 点球、统计和赛果

点球阶段不再走比赛时间。先选先罚队，逐脚进/失，可填球员；符号 ●/×/— 区分结果。点击结果修改或设待重罚，优先处理待罚位置，能撤销最近一脚。首罚队仅开始前更改。五轮提前结束/突然死亡自动判断但不自动确认，修改后需重确认；不进入比赛进球列表。

统计未知留空，已知为零填 0，仅两边都有值的项目显示对比。人物、裁判、解说、赞助在赛前准备编辑，不虚构空缺人员。

赛前准备的「淘汰赛 / 两回合规则」录入首回合比分，按本场主客队身份，客场进球默认关闭；规则设置不能代替裁判和赛规裁定。胜者/晋级/冠军须手动选择对象、勾确认并保存后才显示。比分、事件、点球和两回合修正会取消旧确认，最佳球员可选。

## 延迟、存档和恢复

统一延迟 0–120 秒同时作用于比分、秒级计时和图形，不控制视频本身；建议开播前设置。改延迟会定位到相应历史时点，紧急清屏立即生效。

OBS 刷新/隐藏恢复和断线重连按原时间恢复，不重播过期事件。控制页断线提示服务断开，请恢复后核对日志再操作。服务器重启清图形和队列，计时暂停在最近 5 秒存档检查点；选择保留或补计离线时间后仍须手动继续。异常掉电可能丢失最近未写入操作，应对照日志校准。

导出 .hust.json 包含比赛、日志、草稿和上传图片/视频/字体；导入会替换当前比赛、清屏并暂停，先备份已有项目。换电脑携带完整程序和项目包，安装 Node 后导入。大视频可在停止服务后直接备份整个 runtime。不要同时启动两份服务共用同一数据目录。


补充：待播画面保存入队时的资料快照；普通草稿编辑不会借由比赛事件或自动退场流入直播。明确应用资料会更新当前及等待画面。服务用数据目录进程锁阻止同目录多开。项目包仅包含引用的素材，总量超过180MB时请停服复制完整程序及runtime目录。自动验收为22项测试通过、12组浏览器检查通过；OBS目标设备性能尚未实测。


## v1.1 比分牌修订（2026-10-19）

比分牌主计时器固定显示实际累计比赛时间，例如92:16；右侧补时块仅显示+n分钟，不再在下方显示宣布值/实际补时。后台的兼容补时格式只影响后台读数。进球、黄牌、红牌播出时，仅在对应球队下方展开事件与球员信息，退场收起。其他事件不占此扩展；总比分和点球辅助数值移至顶部小标签。

队徽上自动叠加场上红牌，最多4张；替补/教练不增加。球队资料中可手动+1/-1（0–4）或恢复自动，属于纯图形校正，不改处罚记录；须点击更新直播资料或正式播出才能生效。事件扩展和红牌标记各自有开关。

本版25项自动测试通过，新增6组Edge浏览器检查通过。两套主题示例在design-previews/v1.1，证据validation.json。旧版验收记录保留；OBS实机性能边界不变。


## v1.1.1 修正（2026-10-19）

红牌标记移至对应球队计分板上沿，不依附logo；完整牌高26px，裁切容器高13px，仅露半张，最多4张。后台手动校正和自动处罚逻辑均保留。

事件分钟按“当前所在分钟”取整：常规区间 floor(实际秒/60)+1；达到本阶段规定结束点后为 阶段结束分钟 + floor(超出秒/60)+1。基点由比赛阶段和自定义半场/加时时长决定，与宣布补时无关。

| 阶段/时长 | 实际时间 | 自动事件分钟 |
|---|---|---|
| 上半场，45分钟 | 00:45 | 1′ |
| 上半场，45分钟 | 45:21 | 45+1′ |
| 下半场，45分钟 | 45:21 | 46′ |
| 下半场，45分钟 | 91:21 | 90+2′ |
| 上半场，40分钟 | 41:00 | 40+2′ |
| 下半场，45分钟，宣布+2 | 93:21 | 90+4′ |

宣布补时到时不会暂停、切阶段或自动播全场比分。计时运行时拒绝正式播出全场底部条和全场赛果；恢复计时会撤下/移除当前和待播的全场画面。预览仍与直播分离。应由操作员依裁判实际吹停先暂停或切到全场结束，再手动播出赛果。

已有日志中手动保存的时间不自动重写，纠错可在日志操作。26项自动测试通过，含分钟边界、自定义时长、超补时、运行中全场播出拦截和队列清理；6组本次浏览器验证通过，材料在 design-previews/v1.1.1。


## v1.1.2 客队进球检查与实播监看

客队进球在独立数据目录经实际UI复测正常：待播预览、记账播出、左下播报、客队下方扩展、重播和主客连续队列均通过。原后台大窗口固定待播预览，容易把预览未变化误认为未播出。

新增查看实际播出/返回待播预览切换。明确播出后自动显示与OBS同一时间线的实际输出，编辑仍只修改草稿。事件预览会切回待播，绝不自动播出。日志新增正在实播、排队第N位、输出延迟中、未在播出和已撤销状态；同一事件正在播又排队重播时同时显示。重播不重复加分。

若记录已撤销，不能把它作为有效进球重播；操作员需先确认是否应该恢复记账。只是没有看到有效事件时直接用重播动画。检查不应通过对实际比赛新增测试进球完成，本次验证使用临时比赛，不恢复用户已撤销记录。

新增5组实际浏览器验收通过，证据 design-previews/v1.1.2/validation.json。升级仅前端行为改变，运行中刷新后台即可加载，不必为此重启比赛服务。
