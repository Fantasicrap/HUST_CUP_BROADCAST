# v1.8.6 操作补充

本说明补充v1.8.5 Word指南，不改变整场比赛操作流程。升级只涉及前端、许可及说明；复制更新后刷新后台和OBS浏览器源，不需重启正在计时的比赛服务。

## 作者署名

控制后台左上默认显示 **Fantasticrap@GitHub**。在「系统设置 → 作者署名与开源许可」取消勾选「显示控制后台作者署名」即可隐藏。设置保存在本浏览器，刷新后记住，同浏览器标签页同步；不同电脑或浏览器各自设置。它不更新草稿、不记账、不触发播出。

主路合成、二路进球、回放图形转场均不增加可见作者水印。HTML中有作者元数据，但这不是防篡改或可追踪的隐形像素水印。

项目原创代码采用标准MIT许可。使用、修改、商用与再发布允许，复制或再发布软件及实质部分时须保留原作者版权声明和许可文本；可以追加自己的修改者署名。界面视觉水印可关闭或在分支中移除，不作为额外许可条件。保留根目录LICENSE和AUTHORS.md；第三方字体、上传素材与用户提供插画仍按各自许可使用。

后台「查看作者与开源许可」打开本地about.html，离线可读。

## 二路姓名清晰度

二路与主路使用同一份优设标题黑。旧二路有900字重请求并允许浏览器合成加粗，主路则关闭了字体合成；这是静态对照发现的差异。动态缩放、OBS缩放和编码仍可能影响画面，不能将所有模糊归因于一处。

当前二路姓名明确使用400字重，禁止合成额外加粗，按用户最新要求恢复斜体，撤掉旧版skewX正体校正。姓名测量同时考虑斜体左右字形边界，保留长姓名适配。三档闪动、翻转、球门位置及入网停球逻辑不变。
