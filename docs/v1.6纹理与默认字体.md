# v1.6 纹理与默认字体

系统设置 → 视觉主题与边角，可勾选“深浅交织纹理”。默认开启，两主题共用；选择实色或渐变亚克力、方角或圆角、跟随双方球衣时均可使用。开场、阵容等大面板采用较大的明暗几何纹理，比分牌与事件条更浅。原照片、队徽、媒体与红黄牌符号保持原样。

编辑只作用于草稿；点击“更新直播资料”发布纹理开关。关闭后回到没有纹理的原有底色，比分、计时和队列语义不变。

转播默认字体现为优设标题黑，本地文件public/fonts/YouSheBiaoTiHei.ttf，无需先安装Windows字体；缺字回退Noto。后台为读表保留原Noto字体。原有自定义字体优先；要切回默认，系统设置 → 界面与包装字体 → 恢复默认优设标题黑，再更新直播资料。

独立字体包含TTF原文件和来源说明，没有自动安装器。需要剪辑或AE等软件使用时，解压后双击TTF，在Windows字体窗口选择安装。文件原版权属于优设，官方来源与使用说明在同目录NOTICE中，不属于本项目源码许可或Noto的OFL。

升级前导出并备份runtime，停止旧服务后启动新版，再刷新后台与OBS浏览器源。计时恢复按原机制暂停核对。默认字体和10种阵型排字已检查；既有Word使用指南继续适用于主要操作。


### 阵容和逐线介绍（v1.6.0）

开场标题、赛事标识、队徽进一步放大；阵型右侧球衣由83px放大到112px，姓名由25px放大到32px。四条站位线的密集阵型用104px球衣、30px姓名，右侧面板增高。长姓名按实际文字宽度缩小以完整显示；定妆照同步放大，队长与累计黄牌可以同时显示。逐线翻牌正面球衣扩大至300px，媒体高度仍为450–500px。

每条线介绍时，右侧底部增加“门将／后卫线／中场线／前锋线”横向位置条，使用浅蓝、紫蓝、深蓝渐变、几何纹理和移动光带。从左向右出现，介绍结束向右收起；球衣、翻牌和媒体阶段共用同一时间原点，翻牌不会重播位置条。“赛前准备 → 首发、逐线翻牌与替补”中可独立关闭该条。

顶栏选择“首发阵型”，其旁“阵容球队”可选：只展示主队、只展示客队、主队→翻转→客队。两队依次各自完成已启用的逐线介绍与替补，第一队尾页停留5秒后整页沿竖轴左右翻转900ms，再从另一队最初球衣阵型开始；不会沿用第一队已揭示的照片。两队使用各自姓名、号码、队徽、球衣颜色与媒体。选择先影响待播预览，点击“播出所选画面”才正式播出；时长按当前启用步骤计算，不会按旧45秒提前结束。顶栏独立首发名单和替补名单也可明确选主队或客队。原“完整入场流程”仍逐队独立安排，不因两队顺播设置重复播放。

验证：47项Node测试，60项纹理/字体检查，29项新版阵容检查（两主题10种常用阵型无重叠、长姓名、照片、标记、四线位置条、两队翻转与播出时长），以及既有19组核心布局、22项中心动画回归。使用独立临时服务，不写入当前比赛。
