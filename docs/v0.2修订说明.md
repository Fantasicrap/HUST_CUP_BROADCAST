# 七项反馈的对应实现与操作

版本：v0.2.0-review；日期：2026-10-19。

## 1. 每部分独立选择

后台第一节提供九个独立模块开关；底部比分的五个场景也有各自开关。第三节另有逐线介绍、3D 翻转、照片、视频、累计黄牌、队长标记和介绍后替补衔接开关，每条位置线可独立跳过。关闭首发不妨碍单独采用替补，关闭进球条不妨碍只使用比分牌。

所有开关先保存草稿。当前实播是否采用新开关，要通过「应用资料到实播」明确提交；尝试正式播出已禁用的模块会被服务拒绝。

## 2. 缩小左下角播报

进球宽 600、高约 92；换人宽 600、高约 120。相比旧版 1060×190/238，减少遮挡面积。仍保留队徽、号码、姓名、分钟，换人有文字与上下方向，不靠颜色区分。事件停留默认 6 秒，可设置 1–30 秒。

## 3. 单行比分与上传

单行顺序：主队球衣色条、队徽、名称、主队比分、**赛事 logo**、客队比分、名称、队徽、球衣色条、时间/阶段。总宽 782、高 62，赛事图形始终在双方名称之间。超过 8 字的名称优先使用独立配置的简称，保留完整名称资料。

上传入口在第二节；SVG 内部渐变可用，活动脚本及远程引用不接受。图片比例采用 contain。主客队 +1/−1 下限为 0，先修改草稿，点击应用后更新实播。此操作不生成进球记录；重播动画也不修改比分。

## 4. 放大阵容与可选逐线媒体

左侧信息区宽 310；右侧区域从 x=460 至 1824，y=190 至 944，即 1364×754，和替补共用相同尺寸。

自动流程为：

1. 展示初始球衣阵型。
2. 右侧切为本条线的球衣卡片；门将单张，其余各线并列。
3. 如果启用翻转，用 720ms 3D 翻牌转到媒体面；视频优先于照片，均未传时仍显示球衣。
4. 停留可配置时长后回阵型，该条线采用已上传照片，其余未介绍球员继续球衣。
5. 对其余已选位置线重复。最终显示全部已上传照片；缺照片的球员仍用球衣。

有视频但无照片时：介绍可播视频，回到阵型采用球衣。建议同时上传最终照片与视频。所有视频音量强制为零。播放失败回落到照片或球衣。

球衣采用球队颜色，门将独立设色；每名球员还可覆盖单人颜色，点击「跟随」恢复继承。黄牌在头像左上，C 在右上，两者独立，不互相覆盖。黄色小牌旁数字为累计数。

「动画检查」可以直接查看初始、某条线媒体、最终照片、替补；这些检查选项只作用于草稿预览，正式播出使用实际动画开关和时间线。正式输出刷新会定位到当前步骤，不从门将重新播起。

## 5. 翻至替补

启用「介绍后翻至替补」时，最终照片阵容停留后，右侧整体翻转为同尺寸替补名单，左侧保持球队 logo 与名称。未启用 3D 翻转时直接切换。

替补行展示号码、姓名、括号内位置、累计黄牌；队长也可选。位置输入提供门将、中后卫、边后卫、后腰、前腰、边锋、中锋等建议，允许自行输入。超过 10 人自动两列，最多 24 人；也可独立选择替补模块，不必播放首发。

## 6. 点球进行中简要版

新简版 820×131，画面底部居中，距底 70。展示两队名/徽、点球分数、罚球符号、当前队/轮次。八轮以上窗口显示最近轮次；比分累计仍包含全部轮次。罚进实心点、罚失叉号、待罚短横，能用形状区分。

原来的大面板仍保留作结果展示。后台第五节可以清空示例数据、选择先罚、记罚进/失、撤销，点击某轮可修改或标为待罚重罚。修改后解除结束确认。点球分数和比赛分数独立，不写入进球者列表。满足决胜条件只提示待确认。

## 7. 底部比赛简要比分

第四节选择「开场／开球、半场结束、下半场开场、全场结束、进球后重新开球」，可仅预览或明确播出。主体宽 980、高 82，距底 72；与左上比分互斥。

- 进球后重新开球：上展一行，显示最后一条未取消进球的球员与时间。
- 半场：使用独立录入的半场比分，只列上半场有效进球。
- 全场：使用本场比分，列全部有效进球；点球/乌龙分别用 P/OG 标识。
- 开场、下半场开场：只展示简要比分和场景标签。

默认 5.5 秒后自动恢复左上，可在 5–6 秒间调整。若不采用左上模块，恢复后为空；若关闭「结束后恢复」，停留结束清空。进球较多时两队记录分栏按四条分页，在总停留时间内轮换。

「记录这次进球并 +1」只修改草稿记录与比分，不播放动画；取消记录会同步扣一，并从半场/全场/最后进球展示中排除。单独 ±1 不改进球名单，操作员需保持人工资料一致。

## 存档与连接

上传素材及草稿/实播快照存于 runtime 目录，本机服务关闭后仍保留。后台显示输出连接数；OBS 使用 mode=live 地址。紧急清屏更换播放代次并撤下当前流程，旧的自动恢复不会在之后重新弹出。

本次验证针对浏览器和本地服务，完整赛事计时、专业事件队列、统一延迟及 OBS 实机验收仍待后续完成。
