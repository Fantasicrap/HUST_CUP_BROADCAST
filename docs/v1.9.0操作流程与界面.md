# v1.9.0 操作流程与界面

本次整理控制后台，不改变OBS图形、计时算法、记账或播放规则。刷新后台即可使用；正在运行的比赛服务无需重启。

## 从哪里开始

后台仍默认进入「赛中」，便于已开赛时接管。第一次准备比赛，点击左侧「赛前准备」，按四步完成：

1. **资料**：选择人数制度，填写赛事、双方队名、队徽和球衣色；按需保存两回合规则。新建比赛收在「新比赛或继续原比赛」中，继续原比赛不需要新建。
2. **阵容**：分别编辑两队首发与替补、阵型、队长和累计黄牌、照片或视频。完成后同步名单到比赛，赛中检索才使用这份名单。
3. **画面**：填写裁判、解说、赞助等可选资料；可跳转系统设置选择主题、模块和材质，或预览阵型与开场。可选人物不必填满。
4. **开播**：核对检查列表，处理待同步或待发布提示，预览比分牌，明确发布资料，再播放开场顺播或开球简版。

步骤可前后返回，切换步骤本身不写比赛或播出。检查只验证资料格式和版本是否一致，不能判断填的是不是本场真实名单；示例数据也可能通过，仍需人工核对。

第3步的「通用人物介绍（可选）」单独用于姓名／身份信息条，不会关联球队官员、球员、裁判或解说名单。不用可留空；需要时填写介绍对象姓名与显示身份／职务，顶部选择「人物介绍」后先预览，再明确正式播出。

裁判团队改为「选择岗位 → ＋ 添加裁判 → 填写姓名与学院」，未添加的岗位不占表单位置。主裁判、第一/第二助理、第四官员、附加助理和候补助理均按此添加。附加助理最多2人、候补助理最多1人；附加助理的两行及转播标签均不显示（1）（2）。旧档已填写的人员会自动展开保留。可移除单个岗位，移除只改草稿，发布后才影响正式资料。

## 顶部操作

| 操作 | 用途 |
|---|---|
| 下一步提示 | 根据当前页面和实际比赛阶段提示接下来要做什么 |
| 预览此画面 | 检查选择的包装，不进入直播、不记账 |
| 正式播出此画面 | 正式送播所选模块；当前忙时可能进入队列 |
| 发布资料（不换画面） | 发布队名、队徽、配色和其他草稿资料，不切换当前模块、不重播动画 |
| 结束包装，回到比分牌 | 结束其他包装并清空待播；仅比赛阶段显示左上比分牌，不改变比分和计时 |
| 紧急清屏 | 立即撤下两路包装并清除队列，不自动停表 |

监看顶部标明「实际播出」或「草稿预览 · 不会播出」。赛前、中场、加时、赛后和系统设置中，监看和计时默认收起在「查看实播与计时」内，展开后仍可使用原控制。进入赛中后自动展示，播出入口和紧急清屏始终可见。

「更新直播资料」在新版改名为「发布资料（不换画面）」；「播出所选画面」改名为「正式播出此画面」。v1.8.5 Word中的这两个旧按钮名称按此对应，其他功能仍保留。

## 比赛进行中

实际开球时，可点击下一步区域的「上半场开球 · 开始计时」，它复用计时区的阶段选择与应用。此按钮明确改变比赛阶段并开表，单纯打开赛中页不会开表。

发生事件时，在「发生了什么？」点进球、给牌、换人等入口，填写并检索球员 → 确认预览 → 应用并播出。事件会正常记账，重播动画不重复记账。校准和清零收在计时区「校准时间与清零」；宣布补时仍直接可见，清零仍需确认。

二路动画收在赛中下方「二路进球动画 · 独立输出，不记分」，展开后使用原检索、文字修正、预览与应用操作。主路进球事件仍须单独记账。

## 中场、下半场与赛后

- 上半场尚在进行时，打开中场页不会停表；实际吹停后点击「上半场结束 · 停表并进入中场」，再核对统计和播包装。
- 中场阶段可播半场及下半场开球简版。实际下半场开球时，点击「下半场开球 · 开始计时」，采用当前自定义半场时长对应的起点。
- 加时和点球页提供操作顺序，阶段仍由计时区明确应用，点球仍逐脚录入并人工确认结束。
- 打开赛后页不会结束比赛。实际吹停后点击「全场结束 · 停表」，再核对账本、保存人工确认结果、播赛果、导出项目。

上述按钮只有明确点击才执行，系统不会按页面、补时到点或当前领先自动宣布比赛结束或胜者。

## 验证

独立临时比赛完成7组流程检查及9组原事件回归，浏览器错误为空；检查涵盖只导航不误播、同步/发布差异、名单缺项、开球/中场/全场阶段动作、检索事件、二路入口、点球关联给牌、VAR、OG/P、赞助上传及明暗主题，900/700/390px无页面水平溢出。语法检查通过。
