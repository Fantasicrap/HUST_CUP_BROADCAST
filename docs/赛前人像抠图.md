# 赛前可选人像抠图

赛前准备 → 首发、逐线翻牌与替补 → 勾选「上传球员照片后，进入可选抠图确认」。默认关闭，不影响直接上传原图、透明PNG或视频。

## 安装一次

抠图是额外的本地CPU功能。核心播出仍只需要Node.js；如需自动抠图，另安装64位Python 3.12–3.13（推荐3.12）。在项目目录打开PowerShell，运行：

```powershell
powershell -File .\scripts\setup-portrait.ps1
```

如Python不在PATH，可指定：

```powershell
powershell -File .\scripts\setup-portrait.ps1 -Python "C:\Python312\python.exe"
```

安装脚本只创建本项目的.venv-background环境，并下载rembg CPU依赖及约176MB人像模型到runtime/background。需要一次联网，不需要管理员权限，不更改系统安全设置。如Windows策略阻止脚本，可在已打开的PowerShell中依次执行等价命令：

```powershell
python -m venv .venv-background
.\.venv-background\Scripts\python.exe -m pip install -r .\scripts\portrait-requirements.txt
$env:U2NET_HOME = Join-Path (Get-Location) "runtime/background"
.\.venv-background\Scripts\python.exe .\scripts\setup-portrait.py $env:U2NET_HOME
```

回到后台点击「检查本地抠图环境」，看到就绪即可使用，无需重新下载。安装失败可以再次运行；不会动球队、比赛或原图。下载失败时检查网络，不要关闭Windows安全中心。

## 操作

1. 先选择主队或客队，上传该球员的JPG、PNG或WebP照片（最多12MB、2400万像素）。SVG不进入AI抠图，视频也不处理。
2. 弹窗同时提供原图与棋盘背景预览。点击「生成透明预览」，等待本地处理；使用CPU两个线程，单次最长120秒，避免并发多张。
3. 查看头发、手臂间隙与球衣边缘。点击「采用抠图结果（仅草稿）」才替换照片；「使用原图」可跳过；取消则保留此前照片。
4. 随时可在已上传照片旁点击「抠图」重新处理，或点击「还原原图」。最终照片和原图分别保存，反复处理从原图开始，不重复损失边缘。
5. 在球星卡/逐线介绍及最终照片阵型中预览。图片按完整人物适配，裁去周围多余空白，保留少量安全边距。点击「更新直播资料」或正式播出相应画面后才进入OBS。

处理失败、环境未安装或结果不理想时使用原图即可。复杂背景、多人合照、模糊或肢体被遮挡可能需要外部人工修图后上传透明PNG；AI不能补出原图没有拍到的身体。本版本不提供手工画笔、批量后台抠图或视频背景移除。

## 本地保存与移机

照片处理期间固定使用本地u2net_human_seg模型的CPU推理，不上传照片、不调用云抠图API。只有上述安装步骤联网。原图和已确认结果均在runtime/assets，以内容哈希命名，导出项目包含两者，换电脑不丢图；取消后未采用的临时素材不会被项目包引用。

模型及Python环境不会装入.hust.json或GitHub源码包。换电脑后重新安装可选环境；已有透明照片不需要模型也能正常播出。完整离线移机可复制runtime/background模型及项目目录，但Python虚拟环境通常需要在新机重建。不要将个人runtime提交到GitHub。

实现基于[rembg 2.0.85](https://github.com/danielgatis/rembg/tree/v2.0.85)（MIT）和[U²-Net人像分割模型](https://github.com/xuebinqin/U-2-Net)（上游Apache-2.0）。安装时保留依赖各自许可证；程序固定本地模型，不使用rembg提供的云模型。模型文件按上游MD5 c09ddc2e0104f800e3e1bb4652583d1f校验。环境为可选依赖，不改变主程序许可。

当前环境在Windows、Python3.12和固定依赖清单下完成真实模型验证。高级可选回归命令为node scripts/review-portraits.cjs，需先安装该环境；脚本使用scikit-image附带的NASA astronaut示例人像，不使用个人球员图片。
