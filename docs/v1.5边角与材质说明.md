# v1.5 边角与材质

1. 系统设置 → 视觉主题与边角，选择方角或圆角。两个主题均可使用；旧存档默认方角。
2. 后台立即更新。包装草稿可在预览模块中检查；“实播”监看保持已发布样式。
3. 点击“更新直播资料”才将边角应用到OBS；不重复事件或改动比分。导出项目包含边角配置。
4. 点击“渐变亚克力材质示意”打开只读页面，可选择两主题、方/圆角、五类画面、完整/近看、重播。
5. 按最终确认：底图透出比例0–30%，材质底色至少70%（默认75%），文字与标志保持清晰，白色到蓝色渐变、细边高光与阴影。提案未成为正式主题，实播即使加concept参数也不会采用。
6. 对称包装主体保持高度，从中间左右展开330ms，停顿330ms，然后上下延伸440ms；退出反向执行三段各300ms。紧急清屏立即清空。
7. 下载新版本后保留runtime（比赛与上传素材），停止旧服务再启动，刷新后台与OBS浏览器源。恢复存档后计时暂停，按提示核对是否补计离线时间，再点击计时“应用”继续；不要用演示数据覆盖真实比赛。

示意图：design-previews/v1.5.0/acrylic-detail-comparison.png；交互页面：http://127.0.0.1:3210/material-preview.html。
验证复现：npm test；npm run review。测试需要Edge及开发依赖，正常播出无需npm依赖。全部浏览器回归使用临时独立数据，不操作当前比赛。
