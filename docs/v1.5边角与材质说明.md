# v1.5.1 边角与渐变材质

1. 系统设置 → 视觉主题与边角，选择方角或圆角，两主题均可使用。
2. 图文材质选择“实色”或“渐变亚克力”。旧存档默认实色，可随时切回。
3. 渐变配色选择“跟随双方本场球衣”或“固定白色 → 蓝色”。球衣色在赛前准备中设置，独立于球队品牌色。
4. 跟随球衣：主客队对应区域分别配色，中央保持白色；进球条按球员所属队配色，点球两队行各自配色，文字按深浅调整。
5. 底图透出比例可设0–30%，默认25%；即材质底色至少保留70%不透明度，文字和标志保持清晰，不使用视频模糊滤镜。
6. 修改先保存草稿，后台边角立即变化。图文草稿在预览模块检查；“实播”监看继续使用已发布设置。
7. 点击“更新直播资料”才应用到OBS，不重播事件或改动比分。球衣色后续修改也遵循此发布规则。
8. 全部配置随比赛保存与项目导出。预览URL不能覆盖正式输出。
9. “查看渐变亚克力材质示意”提供只读对比页，可切换两主题、方圆角、画面、完整/近看、配色、透出比例和重播；页面不会自行发布。
10. 对称主体左右展开330ms → 停顿330ms → 上下延伸440ms；退场反向三段各300ms。紧急清屏立即执行。
11. 升级保留runtime，停止旧服务再启动，刷新后台与OBS。恢复存档后计时暂停，核对是否补计离线时间再继续。不要导入演示数据覆盖真实比赛。

示意图见design-previews/v1.5.0和v1.5.1；交互页面：http://127.0.0.1:3210/material-preview.html。
验证复现：npm test；npm run review。测试需要Edge及开发依赖，正常播出无需npm依赖。回归均使用独立临时比赛，不操作当前比赛。
