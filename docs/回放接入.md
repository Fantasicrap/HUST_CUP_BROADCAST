# OBS 回放接入

本系统提供图形转场、REPLAY 角标和可选音效；不录制、选择或播放回放视频。视频由 OBS 回放缓冲、媒体源或外部系统负责。

1. 新增 OBS 浏览器覆盖源，1920×1080，地址 `http://127.0.0.1:3210/transition.html`，置于视频上方。
2. 勾选「场景变为活动状态时刷新浏览器」。每次刷新播放一次 1400ms 图形。`?loop=1` 仅用于循环检查。
3. 0–500ms 展开，500–1200ms 全屏遮挡，1200–1400ms 退出。**推荐在 700ms 切换下层视频**。
4. 先显示/刷新覆盖源，约 700ms 切到回放场景，1400ms 后隐藏覆盖源。精确联动可用 OBS 宏、脚本或回放控制器；本项目不自动控制 OBS 场景。
5. 回现场同样操作。后台勾选回放角标并应用资料；回现场后取消并应用。

合成输出也有回放转场模块，会受统一图文延迟影响；独立 transition.html 不使用比赛延迟，应按 OBS 实际切换时刻触发。

没有额外毒刺视频文件，提供的是浏览器覆盖接入方式。包装短音为项目原创合成，默认关闭、音量可调；能否自动发声取决于 OBS 浏览器音频策略，现场需检查。
